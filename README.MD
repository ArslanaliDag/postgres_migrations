# Database Migration Creator (PostgreSQL)

**Database Migration Creator** — это Windows-приложение, позволяющее быстро и удобно создавать миграции для PostgreSQL на основе шаблонов и SQL-кода.  
Инструмент предназначен для разработчиков, DevOps-инженеров и команд, которые используют собственную систему миграций или интеграцию с CI/CD.

---

## 🚀 Возможности

- **Поддержка нескольких схем (schemas)**  
  Можно выбрать system-defined схему или указать custom-схему вручную.

- **Автоматическое создание структуры миграций**
  - Уникальное имя миграции  
  - Автор  
  - Комментарий  
  - Тип миграции (обычно `ddl`, `dml`, `structure`, `data`, `seed`, `init`, custom)

- **Редактор SQL-кода**  
  - удобное окно с моноширинным шрифтом  
  - поддержка больших скриптов  
  - автоматическое масштабирование при растягивании окна

- **Шаблоны миграций (.sql)**  
  - загрузка списка доступных шаблонов из папки `/Templates`  
  - автоматическая вставка шаблона в SQL-редактор  
  - предварительный просмотр содержимого

- **Генерация Init Script**  
  Автоматически формирует первоначальный набор SQL-инструкций для схемы.

- **Предпросмотр миграции**  
  Показывает итоговый SQL-файл перед сохранением.

- **Создание итогового файла миграции**  
  Формирует файл в формате `YYYYMMDD_HHMM_migration_name.sql`.

---

## 🏁 Запуск

1. Открыть проект в **Visual Studio**.
2. Убедиться, что используется **.NET Framework / .NET WinForms** (в зависимости от версии).
3. Запустить в режиме Debug или собрать Release.

---

## 📦 Требования

- Windows 10/11  
- .NET Framework или .NET Runtime (в зависимости от сборки)  
- PostgreSQL (для дальнейшего выполнения миграций)

---

## 🤝 Для кого подходит

- Backend-разработчики  
- DevOps  
- DBA, которые работают с версиями структуры БД  
- Команды, которые хотят стандартизировать SQL-миграции

---

## ✔ Пример использования

1. Выбрать целевую схему БД.  
2. Указать имя миграции, автора и комментарий.  
3. Выбрать тип миграции.  
4. Написать SQL или загрузить шаблон.  
5. Нажать **Create Migration**.  
6. Готовый SQL-файл появится в папке миграций.
